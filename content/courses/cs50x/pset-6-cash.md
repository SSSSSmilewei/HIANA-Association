# Cash

## 要解决的问题

在名为 `sentimental-cash` 的文件夹中，创建名为 `cash.py` 的文件，编写一个程序：询问用户应找多少零钱，然后输出能凑出这笔零钱所需的最少硬币数。你可以完全照着[习题集 1](/courses/cs50x/learn/pset-1)中的做法来做，不同的是这次你的程序要用 Python 来写，并且你可以假设用户输入的零钱以美元为单位（例如 0.50 美元，而不是 50 美分）。

## 演示

## 要求

- 使用 CS50 库中的
  
  get_float
  
  获取用户的输入，并用
  
  print
  
  输出你的答案。假设可用的硬币只有 25 美分（quarter）、10 美分（dime）、5 美分（nickel）和 1 美分（penny）。
  
  - 我们要求使用 `get_float`，这样你就能处理美元和美分，只是不带美元符号。换句话说，如果某位顾客应找 9.75 美元（比如一份报纸 25 美分，而顾客用 10 美元的钞票付款），就假设你的程序的输入是 `9.75`，而不是 `$9.75` 或 `975`。但如果某位顾客恰好应找 9 美元，就假设你的程序的输入是 `9.00` 或者就是 `9`，同样不会是 `$9` 或 `900`。当然，由于浮点数的特性，你的程序对 `9.0` 和 `9.000` 这样的输入很可能也能正常工作；你不必检查用户的输入是否具有钱数应有的“格式”。
- 如果用户没有提供非负的值，你的程序应当不断重新提示用户输入有效的金额，直到用户照做为止。
- 顺带一提，为了让我们能自动化测试你的代码，我们要求你的程序的最后一行输出只能是最少硬币数：一个整数，后跟一个换行符。

- 以 `python cash.py` 运行你的程序，等待输入提示。输入 `0.15` 并按回车。你的程序应输出 `2`。
- 以 `python cash.py` 运行你的程序，等待输入提示。输入 `1.60` 并按回车。你的程序应输出 `7`。
- 以 `python cash.py` 运行你的程序，等待输入提示。输入 `23` 并按回车。你的程序应输出 `92`。
- 以 `python cash.py` 运行你的程序，等待输入提示。输入 `4.2` 并按回车。你的程序应输出 `18`。

- 以 `python cash.py` 运行你的程序，等待输入提示。输入 `foo` 并按回车。你的程序应拒绝这一输入，例如重新提示用户输入另一个数字。
- 以 `python cash.py` 运行你的程序，等待输入提示。什么都不输入，直接按回车。你的程序应拒绝这一输入，例如重新提示用户输入另一个数字。
