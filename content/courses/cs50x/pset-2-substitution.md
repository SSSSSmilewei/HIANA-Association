# Substitution

## 要解决的问题

在替换密码（substitution cipher）中，我们通过把每个字母替换成另一个字母来“加密”（即以可逆的方式隐藏）一条消息。为此，我们使用一个<em>密钥</em>：在这里，就是把字母表中的每个字母映射到加密时它应该对应的字母。要“解密”消息，消息的接收者需要知道密钥，这样才能逆转这个过程：把加密后的文本（通常称为<em>密文</em>）翻译回原始消息（通常称为<em>明文</em>）。

例如，一个密钥可能是字符串 `NQXPOMAFTRHLZGECYJIUWSKDVB`。这个 26 个字符的密钥意味着 `A`（字母表的第一个字母）应该转换成 `N`（密钥的第一个字符），`B`（字母表的第二个字母）应该转换成 `Q`（密钥的第二个字符），依此类推。

那么，像 `HELLO` 这样的消息，就会按照密钥所确定的映射替换每个字母，加密成 `FOLLE`。

在名为 `substitution` 的文件夹中，创建名为 `substitution.c` 的文件，编写一个程序，让你能用替换密码加密消息。用户执行程序时，应该通过提供命令行参数来决定密钥是什么，而密钥将用于他们在运行时提供的秘密消息。

## 要求

设计并实现一个程序 `substitution`，用替换密码加密消息。

- 在名为 `substitution` 的目录下，名为 `substitution.c` 的文件中实现你的程序。
- 你的程序必须接受单个命令行参数，即用于替换的密钥。密钥本身应当不区分大小写，所以密钥中的任何字符是大写还是小写，都不应影响你程序的行为。
- 如果执行你的程序时没有任何命令行参数，或者命令行参数多于一个，你的程序应该（用 `printf`）打印一条你自己选择的错误信息，并立即从 `main` 返回值 `1`（这通常表示出错）。
- 如果密钥无效（例如不包含 26 个字符、包含任何非字母字符，或者没有恰好包含每个字母一次），你的程序应该（用 `printf`）打印一条你自己选择的错误信息，并立即从 `main` 返回值 `1`。
- 你的程序必须输出 `plaintext:`（不带换行），然后（用 `get_string`）提示用户输入一个明文 `string`。
- 你的程序必须输出 `ciphertext:`（不带换行），后面跟着该明文对应的密文，明文中的每个字母字符都要替换成密文中对应的字符；非字母字符应原样输出。
- 你的程序必须保持大小写：大写字母必须仍是大写字母；小写字母必须仍是小写字母。
- 输出密文之后，应该打印一个换行符。然后你的程序应该通过从 `main` 返回 `0` 来退出。

根据 [manual.cs50.io](https://manual.cs50.io/)，你可能会发现 `ctype.h` 中声明的一个或多个函数很有用。

```
debug50 ./substitution KEY
```

其中 `KEY` 是你作为命令行参数传给程序的密钥。注意，运行

```
debug50 ./substitution
```

会（理想情况下！）让你的程序以提示用户输入密钥而结束。
