# Caesar

![Caesar Cipher](https://cs50.harvard.edu/x/psets/2/caesar/cipher.jpg)

## 要解决的问题

据说，凯撒（没错，就是那个凯撒）曾通过把机密消息中的每个字母移动若干位来“加密”（即以可逆的方式隐藏）这些消息。例如，他可能把 A 写成 B，B 写成 C，C 写成 D，……，并按字母表循环，把 Z 写成 A。于是，要对某人说 HELLO，凯撒可能会写成 IFMMP。收到凯撒这样的消息后，接收者必须朝相反方向把字母移动同样的位数来“解密”。

这个“密码系统”的保密性取决于只有凯撒和接收者知道一个秘密，即凯撒把字母移动的位数（例如 1）。按现代标准来看并不特别安全，但是，嘿，如果你可能是世界上第一个这么做的人，那就相当安全了！

未加密的文本通常称为<em>明文</em>（plaintext）。加密后的文本通常称为<em>密文</em>（ciphertext）。所用的秘密称为<em>密钥</em>（key）。

说得更清楚些，用密钥 \(1\) 加密 `HELLO` 得到 `IFMMP` 的过程如下：

| 明文 | `H` | `E` | `L` | `L` | `O` |
|---|---|---|---|---|---|
| + 密钥 | \(1\) | \(1\) | \(1\) | \(1\) | \(1\) |
| = 密文 | `I` | `F` | `M` | `M` | `P` |

更正式地说，凯撒的算法（即密码）通过把每个字母“旋转” \(k\) 个位置来加密消息。更正式地说，如果 \(p\) 是某个明文（即未加密的消息），\(p_i\) 是 \(p\) 中第 \(i\) 个字符，\(k\) 是秘密密钥（即一个非负整数），那么密文 \(c\) 中的每个字母 \(c_i\) 按下式计算：

\[c_i = (p_i + k)\space\%\space26\]

其中 \(\%\space26\) 在这里表示“除以 26 的余数”。这个公式也许让这种密码显得比实际更复杂，但它其实只是精确表达该算法的一种简洁方式。事实上，为了便于讨论，把 A（或 a）看作 \(0\)，B（或 b）看作 \(1\)，……，H（或 h）看作 \(7\)，I（或 i）看作 \(8\)，……，Z（或 z）看作 \(25\)。假设这次凯撒只想用密钥 \(k\) 为 3 来秘密地对某人说 `Hi`。那么他的明文 \(p\) 是 `Hi`，其明文的第一个字符 \(p_0\) 是 `H`（即 7），第二个字符 \(p_1\) 是 `i`（即 8）。于是他的密文的第一个字符 \(c_0\) 是 `K`，第二个字符 \(c_1\) 是 `L`。明白了吗？

在名为 `caesar` 的文件夹中，创建名为 `caesar.c` 的文件，编写一个程序，让你能用凯撒密码加密消息。用户执行程序时，应该通过提供命令行参数来决定密钥是什么，而密钥将用于他们在运行时提供的秘密消息。我们不一定要假设用户的密钥是一个数字；不过你可以假设，如果它是数字，那就是一个正整数。

## 要求

设计并实现一个程序 `caesar`，用凯撒密码加密消息。

- 在名为 `caesar` 的目录下，名为 `caesar.c` 的文件中实现你的程序。
- 你的程序必须接受单个命令行参数，一个非负整数。为便于讨论，我们称它为 \(k\)。
- 如果执行你的程序时没有任何命令行参数，或者命令行参数多于一个，你的程序应该（用 `printf`）打印一条你自己选择的错误信息，并立即从 `main` 返回值 `1`（这通常表示出错）。
- 如果命令行参数中有任何字符不是十进制数字，你的程序应该打印信息 `Usage: ./caesar key`，并从 `main` 返回值 `1`。
- 不要假设 \(k\) 小于或等于 26。你的程序应该对小于 \(2^{31} - 26\) 的所有非负整数 \(k\) 都能工作。换句话说，如果用户选择的 \(k\) 太大或者大到几乎放不进一个 `int`，导致你的程序最终出错，你不必为此担心。（回忆一下，`int` 可能会溢出。）但是，即使 \(k\) 大于 \(26\)，你的程序输入中的字母字符在输出中也应该仍然是字母字符。例如，如果 \(k\) 是 \(27\)，`A` 不应该变成 `\`，尽管根据 [asciitable.com](https://www.asciitable.com/)，在 ASCII 中 `\` 与 `A` 相距 \(27\) 个位置；`A` 应该变成 `B`，因为只要从 `Z` 循环回到 `A`，`B` 与 `A` 就相距 \(27\) 个位置。
- 你的程序必须输出 `plaintext:  `（带两个空格但不带换行），然后（用 `get_string`）提示用户输入一个明文 `string`。
- 你的程序必须输出 `ciphertext: `（带一个空格但不带换行），后面跟着该明文对应的密文，明文中的每个字母字符都被“旋转” <em>k</em> 个位置；非字母字符应原样输出。
- 你的程序必须保持大小写：大写字母在旋转之后必须仍是大写字母；小写字母在旋转之后必须仍是小写字母。
- 输出密文之后，应该打印一个换行符。然后你的程序应该通过从 `main` 返回 `0` 来退出。

### 统计命令行参数的个数

不管你的伪代码是什么样，我们先只写 C 代码来检查程序运行时是否恰好带有一个命令行参数，再添加其他功能。

具体来说，修改 `caesar.c` 中的 `main`，使得如果用户没有提供命令行参数，或提供了两个或更多，函数就打印 `"Usage: ./caesar key\n"`，然后返回 `1`，从而有效地退出程序。如果用户恰好提供了一个命令行参数，程序应该什么都不打印，直接返回 `0`。因此程序的行为应如下所示。

```
$ ./caesar
Usage: ./caesar key
```

```
$ ./caesar 1 2 3
Usage: ./caesar key
```

```
$ ./caesar 1
```

<details markdown="1"><summary>提示</summary>

- 回忆一下，你可以用 `printf` 打印。
- 回忆一下，函数可以用 `return` 返回一个值。
- 回忆一下，`argc` 包含传给程序的命令行参数的个数，再加上程序自身的名字。

</details>

### 检查密钥

既然你的程序（希望如此！）已经按要求接受输入了，是时候进行下一步了。

在 `caesar.c` 中 `main` 的下方添加一个函数，比如叫 `only_digits`，它接受一个 `string` 作为参数，如果该 `string` 只包含数字 `0` 到 `9`，就返回 `true`，否则返回 `false`。别忘了在 `main` 上方也加上该函数的原型。

<details markdown="1"><summary>提示</summary>

- 你多半会想要这样的原型：
  
  ```
  bool only_digits(string s);
  ```
  
  并且一定要在文件顶部包含 `cs50.h`，这样编译器才能识别 `string`（和 `bool`）。
- 回忆一下，`string` 只不过是由 `char` 组成的数组。
- 回忆一下，`string.h` 中声明的 `strlen` 用来计算 `string` 的长度。
- 根据 [manual.cs50.io](https://manual.cs50.io/)，你可能会发现 `ctype.h` 中声明的 `isdigit` 很有用。但注意它一次只检查一个 `char`！

</details>

然后修改 `main`，使它对 `argv[1]` 调用 `only_digits`。如果该函数返回 `false`，那么 `main` 应该打印 `"Usage: ./caesar key\n"` 并返回 `1`。否则 `main` 直接返回 `0`。因此程序的行为应如下所示：

```
$ ./caesar 42
```

```
$ ./caesar banana
Usage: ./caesar key
```

### 使用密钥

现在修改 `main`，使它把 `argv[1]` 转换成 `int`。根据 [manual.cs50.io](https://manual.cs50.io/)，你可能会发现 `stdlib.h` 中声明的 `atoi` 很有用。然后用 `get_string` 以 `"plaintext:  "` 提示用户输入一些明文。

接着，实现一个函数，比如叫 `rotate`，它接受一个 `char` 和一个 `int` 作为输入，如果该 `char` 是字母（即字母字符），就把它旋转那么多个位置，必要时从 `Z` 循环回 `A`（以及从 `z` 循环回 `a`）。如果该 `char` 不是字母，函数则应原样返回同一个 `char`。

<details markdown="1"><summary>提示</summary>

- 你多半会想要这样的原型：
  
  ```
  char rotate(char c, int n);
  ```
  
  于是像
  
  ```
  rotate('A', 1)
  ```
  
  甚至
  
  ```
  rotate('A', 27)
  ```
  
  这样的函数调用应该返回 `'B'`。而像
  
  ```
  rotate('!', 13)
  ```
  
  这样的函数调用应该返回 `'!'`。
- 回忆一下，你可以用 `(int)` 把 `char` 显式地“转换”（cast）成 `int`，用 `(char)` 把 `int` 转换成 `char`。或者你也可以隐式地做到这一点，只要把其中一个当作另一个来用。
- 你多半会想从任何大写字母中减去 `'A'` 的 ASCII 值，这样在做运算时就能把 `'A'` 当作 `0`，`'B'` 当作 `1`，依此类推。运算完之后再把它加回来。
- 你多半会想从任何小写字母中减去 `'a'` 的 ASCII 值，这样在做运算时就能把 `'a'` 当作 `0`，`'b'` 当作 `1`，依此类推。运算完之后再把它加回来。
- 根据 [manual.cs50.io](https://manual.cs50.io/)，你可能会发现 `ctype.h` 中声明的其他一些函数也很有用。
- 在从 `25` 这样的值算术地“循环回” `0` 时，你多半会发现 `%` 很有用。

</details>

然后修改 `main`，使它打印 `"ciphertext: "`，接着遍历用户明文中的每个 `char`，对每个字符调用 `rotate`，并打印其返回值。

<details markdown="1"><summary>提示</summary>

- 回忆一下，`printf` 可以用 `%c` 打印一个 `char`。
- 如果你调用 `printf` 时完全看不到任何输出，多半是因为你打印的字符超出了 0 到 127 的有效 ASCII 范围。试着暂时把字符当作数字打印（用 `%i` 代替 `%c`），看看你打印的是什么值！

</details>
