## 要做什么

1. 使用你的 GitHub 账号登录 [cs50.dev](https://cs50.dev)
2. 在 codespace 的终端窗口中运行 `update50`，确保你的 codespace 是最新的。
3. 用 Python 提交 [Hello](/courses/cs50x/learn/pset-6-hello)
4. 提交以下其中之一：
   
   - 用 Python 完成[这个版本的 Mario](/courses/cs50x/learn/pset-6-mario-less)，如果你觉得不太有把握
   - 用 Python 完成[这个版本的 Mario](/courses/cs50x/learn/pset-6-mario-more)，如果你觉得比较有把握
5. 提交以下其中之一：
   
   - 用 Python 完成 [Cash](/courses/cs50x/learn/pset-6-cash)，如果你觉得不太有把握
   - 用 Python 完成 [Credit](/courses/cs50x/learn/pset-6-credit)，如果你觉得比较有把握
6. 用 Python 提交 [Readability](/courses/cs50x/learn/pset-6-readability)
7. 用 Python 提交 [DNA](/courses/cs50x/learn/pset-6-dna)

如果你两个版本的 Mario 都提交了，我们会记录两者中较高的分数。如果 Cash 和 Credit 都提交了，我们会记录两者中较高的分数。

## 学术诚信

- 对于 Hello、Mario、Cash、Credit 和 Readability，查看你自己用 C 写的实现，以及别人用 <em>C</em> 写的实现，都是<strong>合理的</strong>。
- 查看别人用 <em>Python</em> 写的同样题目的实现则是<strong>不合理的</strong>。
- 这些题目的目标之一是教你如何自学一门新语言，因此请记住，根据课程大纲，以下做法不仅
  
  合理
  
  ，而且鼓励你为此采用：
  
  - 把你在网上或其他地方找到的几行代码并入你自己的代码，前提是这几行代码本身不是指定题目的解答，并且你注明了这些代码的出处。
  - 到网上或其他地方寻求课程自身讲授之外的指导、参考资料，以及技术难题的解决办法，但不能直接寻求习题集题目或你自己期末项目的现成答案。
