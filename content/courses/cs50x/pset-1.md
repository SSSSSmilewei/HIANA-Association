# 习题集 1

## 要做什么

1. 用你的 GitHub 账号登录 [submit.cs50.io](https://submit.cs50.io)，点击 <strong>Authorize cs50</strong>，然后关闭该标签页。
2. 用你的 GitHub 账号登录 [cs50.dev](https://cs50.dev/)，进入属于你自己的“codespace”。
3. codespace 加载完成后，关闭默认打开的所有 <strong>Welcome</strong> 标签页。
4. 在 codespace 的终端窗口中运行 `update50`，确保你的 codespace 是最新的；如果提示，点击 <strong>Rebuild now</strong>。
5. 完成 [Hello, World](/courses/cs50x/learn/pset-1-world)。
6. 提交 [Hello, It’s Me](/courses/cs50x/learn/pset-1-me)。
7. 提交以下其中之一：
   
   - [这个版本的 Mario](/courses/cs50x/learn/pset-1-mario-less)，如果你觉得没那么有把握
   - [这个版本的 Mario](/courses/cs50x/learn/pset-1-mario-more)，如果你觉得比较有把握
8. 提交以下其中之一：
   
   - [Cash](/courses/cs50x/learn/pset-1-cash)，如果你觉得没那么有把握
   - [Credit](/courses/cs50x/learn/pset-1-credit)，如果你觉得比较有把握

如果你两个版本的 Mario 都提交了，我们会记录两者中较高的分数。如果 Cash 和 Credit 都提交了，我们会记录两者中较高的分数。

## 建议

- 你可以通过[第 1 周](https://cs50.harvard.edu/x/weeks/1/)的源代码试玩 David 在课上演示的任何程序。
- 参阅 CS50 的 [C 语言代码风格指南](https://cs50.readthedocs.io/style/c/)，了解如何改进代码风格。
- 如果用 `make` 编译代码时看到任何错误，先集中精力修复你看到的第一个错误，需要时向上滚动查看。
