# Mario

![screenshot of Mario jumping up pyramid](https://cs50.harvard.edu/x/psets/6/mario/more/pyramids.png)

## 要解决的问题

在名为 `sentimental-mario-more` 的文件夹中，创建名为 `mario.py` 的文件，编写一个程序，用井号（`#`）作为砖块来重现一个半金字塔，就像你在[习题集 1](/courses/cs50x/learn/pset-1)中做的那样。这次你的程序要用 Python 来写！

## 要求

- 为了让题目更有意思，先用 `get_int` 提示用户输入半金字塔的高度，这是一个介于 `1` 和 `8`（含）之间的正整数。（上图中半金字塔的高度恰好是 `4`，每个半金字塔的宽度是 `4`，两者之间隔着 `2` 格的间隙。）
- 如果用户没有提供不大于 `8` 的正整数，你应当再次提示用户重新输入。
- 然后，借助 `print` 和一个或多个循环，生成所需的半金字塔。
- 注意让金字塔的左下角与终端窗口的左边缘对齐，确保两个金字塔之间有两个空格，并且每一行最后一组井号之后没有多余的空格。

## 如何测试

虽然这道题可以使用 `check50`，但我们鼓励你先自己针对下面每一项测试你的代码。

- 以 `python mario.py` 运行你的程序，等待输入提示。输入 `-1` 并按回车。你的程序应拒绝这一输入，例如重新提示用户输入另一个数字。
- 以 `python mario.py` 运行你的程序，等待输入提示。输入 `0` 并按回车。你的程序应拒绝这一输入，例如重新提示用户输入另一个数字。
- 以 `python mario.py` 运行你的程序，等待输入提示。输入 `1` 并按回车。你的程序应生成下面的输出。请确保金字塔对齐到终端的左下角，并且每行末尾没有多余的空格。

```
#  #
```

- 以 `python mario.py` 运行你的程序，等待输入提示。输入 `2` 并按回车。你的程序应生成下面的输出。请确保金字塔对齐到终端的左下角，并且每行末尾没有多余的空格。

```

##  ##
```

- 以 `python mario.py` 运行你的程序，等待输入提示。输入 `8` 并按回车。你的程序应生成下面的输出。请确保金字塔对齐到终端的左下角，并且每行末尾没有多余的空格。

```
 #  #
```
